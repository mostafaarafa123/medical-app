#  Medical Appointment Booking System

A lightweight, interactive web application built with Python and Streamlit. This application allows users to securely register, log in, browse doctors by specialty, and book medical appointments. 

The project demonstrates solid backend logic, session state management, and data persistence using Pandas and CSV files as a local database structure.

##  Key Features
- ** User Authentication:** Secure login and registration system with user data stored locally.
- ** Doctor Management:** View available doctors, filter by specialties (Dentistry, Surgery, Physiotherapy, Internal Medicine), and dynamically add new doctors to the directory.
- ** Smart Search:** Real-time search functionality to find doctors by name or specialization.
- ** Appointment Booking:** Interactive interface for patients to select specific dates and times for their appointments.
- ** Data Persistence:** User credentials and doctor directories are automatically saved and loaded from `.csv` files to maintain state across sessions.

##  Tech Stack
- **Language:** Python
- **Framework:** Streamlit (Frontend UI & State Management)
- **Data Handling:** Pandas (Data manipulation and CSV storage)
- **OS Integration:** Python `os` module for file path verification
